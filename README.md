# InterPe C++ Games

This repository contains four console-based games developed in C++ during my InterPe internship.

## Projects

### 1. Guess the Number
A game where the player tries to guess a randomly generated number.

### 2. Tic-Tac-Toe
A two-player game where players take turns placing X and O on a 3×3 board.

### 3. Connect Four
A two-player game where players drop pieces into columns and try to connect four pieces in a row.

### 4. Rock Paper Scissors
A simple game where the player competes against the computer using Rock, Paper, or Scissors.

## Technologies Used

- C++
- C++ Standard Library
- Console-based Programming

## Internship

These projects were developed as part of my C++ internship at InterPe.
